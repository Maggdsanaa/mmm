# رياضيات 1 (Android)
تطبيق عربي RTL يعمل دون إنترنت، محتواه وحدة «المعادلات الجبرية والمتباينات» (صفحات 1–65 من الملزمة):
شرح الدروس + بنك أسئلة الملزمة + أسئلة مولّدة تلقائيًا. التدريب بالاختيار من متعدد وصح/غلط فقط (دون كتابة إجابات) مع عرض الحل على خط الأعداد.

إعداد المطور Maggd Alosimi

## البناء
GitHub Actions يبني الـ APK عند كل push (Artifact: math1-debug-apk). محليًا: Android Studio أو `gradle assembleDebug`.

## ملاحظات على الملزمة
- تمرين المحددات (4) في إجابات الملزمة (Δ=7) لا يتطابق مع المصفوفة المطبوعة (محددها 3)، لذلك لم يُدرج.
- معادلة x·√(x²−1)=0: الملزمة تقبل x=0 لكنه يجعل ما تحت الجذر سالبًا، فاعتُمد {1, −1} مع ملاحظة (needsReview).

## الرسوم التفاعلية
مستكشفات بمنزلقات: خطية، نظام معادلتين (تقاطع مستقيمين + كرامر)، تربيعية ومتباينتها، قيمة مطلقة، جذرية، إشارة المقدار، ومختبر المتباينات على خط الأعداد.
