# نظام الحضور الجامعي بـ NFC — بدون خادم وبدون إنترنت

لا يوجد خادم. **تطبيق المسؤول هو المرجع الوحيد**، والملفات تنتقل بين الأشخاص (واتساب/إيميل)،
والحضور نفسه يتم بين هاتفي الطالب والدكتور عبر NFC.

| المكوّن | الدور |
|---|---|
| `admin/` | المسؤول: المواد، الطلاب، الدكاترة، توليد الأكواد، تصدير كشف مشفّر لكل دكتور، استيراد ملفات الحضور، التقارير، نسخة احتياطية |
| `doctor/` | الدكتور: يستورد ملف الكشف + كوده، يبدأ جلسة حضور، يصدّر ملف الحضور للمسؤول |
| `student/` | الطالب: يكتب كوده مرة واحدة، ثم يقرّب هاتفه من هاتف الدكتور |
| `core/` | الأكواد، التشفير، البروتوكول، صيغة الكشف (مشتركة + اختبارات) |
| `tools/CoreReference.java` | نسخة مرجعية بجافا من منطق core، تُشغَّل مباشرة للتحقق (`java tools/CoreReference.java`) |

## التدفق
1. **المسؤول** يضيف المواد ثم يلصق الطلاب والدكاترة ← تُولَّد **أكواد من 12 خانة** (`XXXX-XXXX-XXXX`) بخانة تحقق تكشف خطأ الكتابة.
2. يسلّم كل طالب كوده، وكل دكتور كوده. (تصدير CSV)
3. **الطالب** يكتب كوده مرة واحدة في تطبيقه (لا إنترنت).
4. المسؤول يضغط «تصدير كشف» للدكتور ← ملف **مشفّر بكود الدكتور** يُرسَل بواتساب/إيميل (هذه هي مرة الإنترنت الوحيدة).
5. **الدكتور** يختار الملف ويكتب كوده ← تظهر مواده وطلابه (وسوم الطلاب ومفاتيح مشتقة من أكوادهم، لا الأكواد نفسها).
6. **أول تقريب** بين هاتف الطالب والدكتور: الطالب يثبت معرفته بكوده (HMAC) وحيازته لهاتفه (توقيع ECDSA من Keystore)،
   فيرتبط هاتفه بهويته وتصله بياناته ومواد الدكتور تلقائيًا.
7. بعد المحاضرات: الدكتور «إرسال الحضور للإدارة» ← ملف مشفّر ← المسؤول «استيراد حضور دكتور» ← التقارير وCSV.

## الحماية
- كل لمسة فيها nonce جديد ووقت من ساعة الدكتور ← لا يمكن إعادة إرسال رد قديم.
- الكود يرتبط بجهاز واحد؛ كود على جهاز آخر ← `KEY_MISMATCH`. المسؤول يستطيع إصدار «كود جديد» وإعادة تصدير الكشف، فيُلغى الربط القديم.
- تنبيه في التقارير عند ظهور طالب بجهازين مختلفين (كود مشارَك).
- ملفات الكشف والحضور والنسخ الاحتياطية: AES-GCM بمفتاح مشتق من الكود (PBKDF2)، وأي تعديل بايت يُفشل الفتح.
- قيد UNIQUE(sessionId, studentId) يمنع التسجيل المكرر.

## مهم للمسؤول
- **هاتف المسؤول هو المرجع الوحيد؛ إن ضاع ضاعت الأكواد.** استخدم «إنشاء نسخة احتياطية مشفّرة» من تبويب التقارير، واحفظ النسخة خارج الهاتف وكودها منفصلًا.
- تغيير كود دكتور يجعل الملفات القديمة لا تُفتح بكوده الجديد؛ أعد التصدير.
